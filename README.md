# sauce
sauce is a scripting language that can be used to make small and safe shareable executables.
sauce can be used to make games, if that's your thing.

## How to get started
1. Download the compiler for sauce
2. Create a file ending in `.sauce`
3. Write some code
4. Double click to run or type `sauce myfile.sauce`

## Goals
sauce is supposed to be fast and small. It's also meant to run fine on older less performant systems.
sauce also provides a softer layer for graphic manipulation making it easier to create native running GUI's.

## Why was this made?
I want to teach kids programming. It's hard to make that jump from block languages like Scratch and CodeHS to the complexity of writing actual code. This intends to solve that by bridging what the code is actually doing with what the code literally says.

This is definitely not for everyone, but it might help some people make that connection quicker.
